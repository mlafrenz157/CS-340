# CS-340
How do you write programs that are maintainable, readable, and adaptable?
I try to keep programs maintainable by separating different responsibilities into different parts of the code. In this project, the CRUD Python module handled the database connection and database operations, while the dashboard code handled the user interface and interactions. This made the code easier to understand and reuse because I did not have to rewrite the database logic inside the dashboard.
One advantage of this approach was that I could use the same CRUD module from Project One again in Project Two. If something about the database connection or CRUD operations needed to change, I could update the module instead of changing every part of the dashboard. In the future, the same type of module could be reused for another application that needs to access the same database, such as a reporting tool, another dashboard, or a different front-end application.

How do you approach a problem as a computer scientist?
I try to break a larger problem into smaller pieces and get each part working before moving on to the next one. For the Grazioso Salvare project, I first focused on getting the database and CRUD operations working. After that, I connected the database to the dashboard, added the filters, and then added the chart and map.
This project was different from some earlier assignments because the pieces depended on each other more. Instead of writing one small program to solve one problem, I had to think about how the database, Python module, dashboard, and user interactions all worked together. In future database projects, I would continue to start with the client's requirements, determine what data needs to be stored or queried, build and test the database logic first, and then connect it to the user-facing application.

What do computer scientists do, and why does it matter?
Computer scientists use software, data, and problem-solving techniques to create systems that make tasks easier, faster, and more reliable. They do more than just write code. They also need to understand the problem being solved, organize data, design systems, test their work, and make software that other people can actually use.
For a company like Grazioso Salvare, this project could make it much easier to find animals that meet specific training requirements. Instead of manually searching through a large amount of shelter data, users can select a rescue type and immediately see matching animals, their breeds, and their locations. This can save time and make the information easier to understand and use.
